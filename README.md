# RGB Strip Experiment (`rgb-strip`)

This directory is an experiment for controlling a Bluetooth LED strip (`QHM-F430`, MAC: `12:08:20:00:F4:30`) using Python and the [`led-ble`](https://github.com/Bluetooth-Devices/led-ble) library.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the test script to set the LED strip to dim green:
   ```bash
   python3 test_led.py
   ```
